# Software Engineering

A daily portfolio of software engineering projects — one new project every day for six months (Oct 2026 – Apr 2027).

Where [cs-projects](https://github.com/abubakaromar18/cs-projects) covers breadth across computer science, this repo focuses on **how software is engineered**: design principles and patterns, testing discipline, API and data design, architecture, concurrency, distributed systems, security, DevOps, observability, performance, tooling, and full system-design capstones.

Every project is a complete, working codebase with:
- Clean, idiomatic source code in the stack listed for it
- Automated tests
- Standard build/project files for its ecosystem
- A README explaining the engineering concepts it demonstrates, how to run it, and how it could be extended
